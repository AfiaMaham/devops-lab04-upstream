# Contributing

A pull request to this repository is accepted when:

- it adds exactly one file, under `students/`;
- the file is named after the author's roll number, in capitals, with a
  `.md` extension;
- the file contains the author's name and roll number, and nothing else;
- no other file in the repository is modified;
- the branch is up to date with `main`.

Pull requests that edit another student's file, or that modify `README.md`,
will be closed with a comment explaining why. That is also a review, and
reading the reason is part of the exercise.
